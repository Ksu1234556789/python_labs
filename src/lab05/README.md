# Реализованные функции и стратегии
## Функции-стратегии сортировки
## Реализованы стратегии сортировки:


- по названию курса;


- по преподавателю;


- по стоимости курса;


- по количеству часов;


- по количеству студентов;


- по нескольким атрибутам одновременно.


## Примеры:
- `school.sort_by(st.by_title)`

- `school.sort_by(st.by_cost)`

- `school.sort_by(st.by_type_and_cost)`

## Использование lambda:
- `school.sort_by(lambda c: c.students_count, reverse=True)`

## Функции-фильтры
## Реализованы функции фильтрации:


- активных курсов


- дорогих курсов


- популярных курсов


- курсов определённого типа


## Примеры:
- `school.filter_by(st.is_expensive)`
- `school.filter_by(st.is_programming)`

## Использование map()

### Функция map() применяется для:

- извлечения названий курсов


- преобразования объектов в словари

- создания строк-сводок


- вычисления стоимости со скидкой


## Примеры:
- `school.map(st.extract_title)`
- `school.map(st.to_dict)`
## Использование lambda:
`school.map(lambda c: f"{c.title}: {c.calculate()} руб")`

## Фабрики функций
## Реализованы функции высшего порядка:


- `make_price_filter()`


- `make_min_students_filter()`


- `make_hours_range_filter()`


- `make_type_filter()`


## Пример:
- `cheap_filter = st.make_price_filter(3000)`
- `result = school.filter_by(cheap_filter)`

## Паттерн «Стратегия»

Паттерн реализован через callable-объекты.

### Созданы стратегии:


- DiscountStrategy


- ActivateStrategy


- UpgradeStrategy


- LabelStrategy


Каждая стратегия реализует метод __call__().

Пример:

- `strategy = st.DiscountStrategy(15)`

- `result = school.map(strategy)`

## Методы коллекции
## В классе OnlineSchool реализованы методы:

- `sort_by()`

Сортировка коллекции по функции-ключу:

`school.sort_by(st.by_cost)`

- `filter_by()`

Фильтрация коллекции по предикату:

`school.filter_by(st.is_active)`

- `apply()`

Применение функции ко всем элементам коллекции:

`school.apply(st.UpgradeStrategy(3))`
