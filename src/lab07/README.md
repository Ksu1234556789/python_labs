lab07/

├── cli.py # CLI-интерфейс: меню, ввод/вывод, форматирование
├── app.py # Бизнес-логика: CRUD, поиск, фильтрация, сортировка
├── exceptions.py # Пользовательские исключения
├── storage.py # Сохранение и загрузка данных в JSON
├── base.py # Базовый абстрактный класс Course 
├── models.py # Дочерние классы курсов 
├── online_school.py # Коллекция OnlineSchool 
├── strategies.py # Стратегии сортировки и фильтрации
├── interfaces.py # Интерфейсы Printable и Comparable 
├── courses_data.json # Файл с сохранёнными данными курсов
└── README.md # Документация


### Назначение файлов:

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа. Инициализирует менеджер, загружает данные из JSON при старте, запускает CLI |
| `cli.py` | Интерфейс командной строки. Только ввод/вывод, никакой бизнес-логики. Форматирует вывод, обрабатывает ошибки ввода |
| `app.py` | Бизнес-логика. Управляет коллекцией курсов: добавление, удаление, поиск, фильтрация, сортировка, сохранение/загрузка |
| `exceptions.py` | Пользовательские исключения: `CourseNotFoundError`, `DuplicateCourseError`, `ValidationError`, `StorageError` |
| `storage.py` | Низкоуровневые функции чтения/записи JSON-файлов |
| `base.py` | Абстрактный базовый класс `Course` с общей логикой, валидацией и абстрактными методами |
| `models.py` | Конкретные классы: `ProgrammingCourse`, `LanguageCourse`, `BusinessCourse` с уникальными атрибутами |
| `online_school.py` | Класс коллекции `OnlineSchool` с методами добавления, удаления, поиска, фильтрации, сортировки |
| `strategies.py` | Функции-стратегии для сортировки (`by_title`, `by_cost` и др.) и фильтрации (`is_active`, `is_programming` и др.), фабрики функций |
| `interfaces.py` | Абстрактные классы `Printable` и `Comparable` для полиморфного поведения |

## 3. Описание CLI

### Главное меню


│ 1. Добавить курс │
│ 2. Показать все курсы │
│ 3. Найти курс по названию │
│ 4. Фильтровать курсы │
│ 5. Сортировать курсы │
│ 6. Удалить курс │
│ 7. Сохранить данные │
│ 0. Выход │


### Реализованные пункты меню:

1. **Добавить курс** — создание курса одного из трёх типов:
   - Курс программирования (доп. поля: язык, количество проектов)
   - Языковой курс (доп. поля: язык, уровень A1-C2)
   - Бизнес-курс (доп. поля: сертификат, компания-партнёр)
   - Автоформатирование: название и преподаватель с заглавной буквы

2. **Показать все курсы** — форматированный вывод с иконками типов, стоимостью, статусом

3. **Найти курс по названию** — поиск по подстроке, вывод всех совпадений

4. **Фильтровать курсы** — подменю с вариантами:
   - По типу курса (programming/language/business)
   - По диапазону цен (min-max)
   - Только активные
   - По минимальному количеству студентов

5. **Сортировать курсы** — подменю с вариантами:
   - По названию
   - По преподавателю
   - По стоимости
   - По часам
   - По количеству студентов

6. **Удалить курс** — поиск по названию и преподавателю, подтверждение (y/n)

7. **Сохранить данные** — запись текущей коллекции в JSON-файл

0. **Выход** — предложение сохранить данные перед выходом

### Обработка ошибок ввода:

- **Неверный пункт меню** — сообщение "Неверный пункт меню. Попробуйте снова."
- **Ввод строки вместо числа** — перехват `ValueError`, сообщение "Введите целое число"
- **Пустой ввод** — проверка на пустую строку, запрос повторного ввода
- **Дубликат курса** — собственное исключение `DuplicateCourseError`, сообщение с названием и преподавателем
- **Курс не найден** — собственное исключение `CourseNotFoundError`
- **Некорректный тип/уровень** — валидация через `ValidationError`, подсказка допустимых значений

### Сохранение и загрузка данных:

- **Автозагрузка** при запуске: если файл `courses_data.json` существует, данные загружаются автоматически
- **Автосохранение** при выходе: запрос подтверждения `Сохранить данные перед выходом? (y/n)`
- **Ручное сохранение**: пункт меню 7
- **Формат данных**: JSON с полной информацией о каждом курсе, включая тип и специфичные атрибуты
- **Расположение файла**: всегда в папке `lab07/`, независимо от места запуска

## 5. Вывод

В ходе выполнения лабораторной работы были изучены и применены на практике:

- **Разбиение на модули и слои** — архитектура из 7+ модулей с чётким разделением ответственности: CLI (ввод/вывод), App (бизнес-логика), Storage (работа с файлами), Models (предметная область)
- **CLI-интерфейс** — реализация интерактивного консольного меню с валидацией ввода, форматированным выводом, подтверждением опасных операций
- **Обработка исключений** — создание иерархии пользовательских исключений (`CourseError` → `CourseNotFoundError`, `DuplicateCourseError`, `ValidationError`), перехват и обработка на уровне CLI
- **Работа с файлами** — сериализация коллекции в JSON, автоматическая загрузка при старте, сохранение при выходе с подтверждением
- **Типизация** — аннотации типов у всех публичных методов и функций (`-> None`, `-> List[Course]`, `-> Optional[Course]`), docstring-комментарии
- **Паттерны проектирования** — Стратегия (сортировка/фильтрация), Фабрика (создание фильтров), Декоратор (валидация в свойствах)
