## Описание реализованной иерархии классов

### Базовый класс: `Course` (абстрактный)
Базовый класс из ЛР-1, определяющий общий интерфейс для всех курсов.

**Атрибуты:**
- `title` — название курса
- `teacher` — преподаватель
- `hours` — количество часов
- `students_count` — количество студентов
- `active` — статус активности

**Абстрактные методы (интерфейс):**
- `process()` — общий метод обработки курса (полиморфный)
- `calculate()` — расчёт стоимости курса (полиморфный)

**Общие методы:**
- `add_student()` / `remove_student()` — управление студентами
- `close()` / `open()` — управление статусом курса

### Дочерний класс 1: `ProgrammingCourse`
Курс программирования.

**Новые атрибуты:**
- `language` — язык программирования (Python, Java, JavaScript)
- `project_count` — количество проектов на курсе

**Новые методы:**
- `add_project()` — добавить проект к курсу

**Переопределённые методы:**
- `process()` — возвращает информацию о курсе программирования
- `calculate()` — стоимость с наценкой 30% + бонус за проекты (500р за проект)

### Дочерний класс 2: `LanguageCourse`
Языковой курс.

**Новые атрибуты:**
- `language` — изучаемый язык (English, German, Spanish)
- `level` — уровень владения (A1, A2, B1, B2, C1, C2)
- `native_speaker` — ведёт ли носитель языка

**Новые методы:**
- `set_native_speaker()` — установить признак носителя языка
- `upgrade_level()` — повысить уровень курса

**Переопределённые методы:**
- `process()` — возвращает информацию о языковом курсе
- `calculate()` — стоимость зависит от уровня (коэффициент 0.8-2.0) и носителя (+30%)

### Дочерний класс 3: `BusinessCourse`
Бизнес-курс.

**Новые атрибуты:**
- `certificate` — выдаётся ли сертификат
- `company_partner` — компания-партнёр

**Новые методы:**
- `has_partner()` — проверка наличия партнёра
- `issue_certificate()` — активировать выдачу сертификата

**Переопределённые методы:**
- `process()` — возвращает информацию о бизнес-курсе
- `calculate()` — стоимость с наценкой 40% за сертификат и скидкой 15% при наличии партнёра

### Различия между классами

| Характеристика | ProgrammingCourse | LanguageCourse | BusinessCourse |
|----------------|-------------------|----------------|----------------|
| **Специфика** | Программирование | Изучение языков | Бизнес-обучение |
| **Уникальные атрибуты** | language, project_count | language, level, native_speaker | certificate, company_partner |
| **Формула стоимости** | База × 1.3 + проекты × 500 | База × уровень × носитель | База × сертификат × партнёр |
| **Уникальные методы** | add_project() | upgrade_level() | issue_certificate() |

## Интеграция с коллекцией

Класс `OnlineSchool` расширен новыми методами для работы с иерархией:

### Методы фильтрации по типу
- `get_by_type(course_type)` — получить курсы указанного типа
- `get_programming_courses()` — получить все курсы программирования
- `get_language_courses()` — получить все языковые курсы
- `get_business_courses()` — получить все бизнес-курсы
- `filter_by_type(course_type)` — создать новую коллекцию из курсов одного типа

### Статистика
- `get_statistics_by_type()` — статистика по типам (количество, средняя стоимость, среднее студентов)

### Сортировка
- `sort_by_cost()` — сортировка по стоимости курса
