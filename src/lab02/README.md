## OnlineSchool
### В работе реализован контейнерный класс OnlineSchool, который хранит и управляет объектами класса Course (из ЛР-1).
### Коллекция позволяет:
- хранить множество курсов
- управлять добавлением и удалением
- выполнять поиск и фильтрацию
- сортировать объекты
- работать с коллекцией как с обычным списком

## Атрибуты класса
- `_items` — список объектов Course, хранящихся в коллекции

## Основные методы
### Управление коллекцией
- add(course) — добавить курс (с проверкой типа и дубликатов)
- remove(course) — удалить курс
- remove_at(index) — удалить курс по индексу
- clear() — очистить коллекцию
- is_empty() — проверить, пуста ли коллекция

### Получение данных
- get_all() — вернуть список всех курсов
- `__len__()` — количество курсов (len(collection))
- `__iter__()` — итерация (for course in collection)
- `__getitem__(index)` — доступ по индексу (collection[0])

### Поиск
- find_by_title(title) — поиск по названию
- find_by_teacher(teacher) — поиск по преподавателю
- find_by_title_contains(substring) — поиск по части названия
- find_active() — найти активные курсы

### Сортировка
- sort(key, reverse=False) — универсальная сортировка
- sort_by_title() — по названию
- sort_by_teacher() — по преподавателю
- sort_by_hours() — по количеству часов
- sort_by_students_count() — по количеству студентов

### Фильтрация (логические операции)
#### Методы возвращают новую коллекцию:
- get_active_courses() — только активные курсы
- get_closed_courses() — только закрытые курсы
- get_courses_with_students(min, max) — по количеству студентов
- get_courses_by_hours_range(min, max) — по диапазону часов

### Магические методы
- `__str__` — красивый вывод коллекции
- `__repr__` — техническое представление


## Ограничения
- можно добавлять только объекты Course
- нельзя добавлять дубликаты (по названию и преподавателю)
- индексация с проверкой границ
- строгая типизация аргументов
