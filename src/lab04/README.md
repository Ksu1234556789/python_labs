# Описание реализованных интерфейсов

## Интерфейс `Printable`
Интерфейс для объектов, которые можно выводить в текстовом виде.

### Абстрактный метод:
- `to_string()` — возвращает строковое представление объекта.

### Назначение:
Позволяет работать с объектами разных типов через единый интерфейс вывода.

---

## Интерфейс `Comparable`
Интерфейс для сравнения объектов.

### Абстрактный метод:
- `compare_to(other)` — сравнивает текущий объект с другим.

### Возвращаемые значения:
- `1` — объект больше
- `0` — объекты равны
- `-1` — объект меньше

### Назначение:
Используется для универсального сравнения и сортировки объектов.

# Полиморфизм через интерфейсы

В лабораторной работе реализован полиморфизм через единый интерфейс.

Объекты разных типов обрабатываются одинаково:
